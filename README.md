## 导入方法

1. 下载 `Scripty-Classics.txtpack`。
2. 打开剧本单词，在「阅读 → 导入本地书」选择书包并输入密码。
3. 新版 App 遇到重复书籍时会询问「覆盖」或「跳过」。想更新已有书目时选「覆盖」，只想补齐新书时选「跳过」。导入完成后在本地书架阅读。导入功能受 App 内权益设置控制。
